# Phase 3 test checklist: class notebook

Use two browsers: one as the teacher, one as a learner. The notebook is on the class page (Notebook tab) and, while teaching, behind the Notebook button. Learners have a Notebook button on their home page and in every lesson.

## Entries
- [ ] Teacher: + Word with only the core fields (word, part of speech, meaning, example). It should take about 10 seconds. Open "More details" and fill in a few fields from Form, Pronunciation, Use and Learner help.
- [ ] Teacher: + Note with formatting (bold, list, highlight) and tags.
- [ ] Learner sees both straight away, with the listen button, CEFR badge and "More details".
- [ ] Teacher: edit an entry, then History → Restore the earlier version. Hide an entry (learners stop seeing it), show it again, delete one.

## Permissions (Settings tab)
- [ ] View only: learners see no + buttons and no Edit.
- [ ] Learners can add: a learner adds a word and can edit it, but can't edit the teacher's entries. The card shows who added it and who last edited it.
- [ ] Learners can add and edit all: a learner edits the teacher's entry; "edited by" appears.
- [ ] Review before publishing: a learner's new entry shows "waiting for the teacher" to them only; the teacher's Pending tab shows it with Approve and Reject. A learner's edit appears under the entry as a proposed change.
- [ ] Block one learner: their + buttons disappear at once; other learners keep theirs.

## My notebook (learner)
- [ ] "Save to my notebook" on a class entry; it appears under My notebook and the button changes to "In my notebook".
- [ ] Add a private word with a translation; the teacher never sees it.
- [ ] "+ My translation" on a class entry: saved privately and shown in blue pen on the card.

## From a task
- [ ] Teacher, in the editor: select a word → right-click → "Add to the class notebook". The drawer opens with the word and the sentence filled in.
- [ ] Teacher, while teaching: select a word in the task → "Add to notebook".
- [ ] Learner: select a word in a task → "Class notebook" (only if allowed) or "My notebook".

## Grammar and vocabulary banks
- [ ] Teacher: Grammar bank → + Page → Edit: a title, the rule, examples and a couple of practice questions from the / menu; choose a topic. Pages group by topic.
- [ ] Learner: opens the page, answers the practice and presses "Check my practice".
- [ ] In a task: / → "Grammar bank link" or "Vocabulary bank link" → choose a page. The card opens the page in the notebook drawer for the learner.
- [ ] Inline: select text → Link → Notebook tab → choose a page.

## Search and filter
- [ ] Search by word, meaning or note text; filter by words/notes, lesson, part of speech, CEFR level and tag.

## Known limits
- Practice answers on bank pages are stored with the page and are readable by learners who look at the data directly; they are practice, not marks.
- The notebook isn't in the text export yet (Phase 4 full copy).
