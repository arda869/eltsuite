# Phase 2 test checklist

Use two browsers (or one normal and one private window): one signed in as the teacher, one as a learner. A phone or a narrow window helps for the mobile checks. Start teaching the lesson before the live checks.

## 2a Live teaching extras
- [ ] **Pointer:** turn it on and point at a word. The learner sees the red dot on the same word at any text size, and it fades after 2 seconds of no movement.
- [ ] **Signals:** the learner raises a hand, says "I'm stuck" and sends a reaction. The teacher sees them in the session strip and the live grid. Lower all hands.
- [ ] **Timer and picker:** start a 1-minute timer; everyone sees it and hears a chime at the end. Pick a learner; the picked learner sees "It's your turn".
- [ ] **Spotlight:** show one learner's answer from their detail view. The class sees it without the name.
- [ ] **Announcements:** send to the whole class and to some learners, with a link and a chime. Check "Got it", Remind and Take back.

## 2b Annotations and correction codes
- [ ] Select text while teaching and highlight it (3 colours), underline it and add a comment, as Class and as Only me. The learner sees only the Class ones and can reply.
- [ ] Mark a learner's long answer with codes. Ask for corrections, correct it as the learner, send it, then approve it as the teacher.

## 2c Board
- [ ] **Lesson board:** Board button → draw, add a second page, rename it and move it, and use "Add a page from another lesson". Do this before class.
- [ ] **While teaching:** open the board. The learner sees it and follows your page; the page tabs move learners with you.
- [ ] **Tools:** pen, highlighter, line, arrow, rectangle, ellipse, text (click a text to edit it), eraser, undo and Clear.
- [ ] **Pictures:** add one from a file and by pasting. Select it, move it, resize it from the corner, and delete it.
- [ ] **Who can draw:** "Everyone can draw" and one named learner. The learner sees "You have the pen" and can draw; their strokes appear for you.
- [ ] **Board in the text:** / → Board, prepare it in the editor; it is live in the lesson.
- [ ] **Draw on the teaching screen:** Draw (D) → pen and highlight on the task. Change task and it is gone; nothing reaches learners.

## 2d Groups, versions and who sees a task
- [ ] **Groups:** make random pairs, random groups of 3, level groups and an empty set. Drag learners between rooms, rename the rooms, Shuffle, and delete a set.
- [ ] **Who sees this:** set a task to one group and then to two named learners. Learners outside it don't see the task at all.
- [ ] **Versions:** Make version B, then Make level versions on another task. The versions sit under the task in your list. Edit each one and rename a version.
- [ ] **Give out versions:**
  - [ ] Same for everyone: switch which version.
  - [ ] Per room: map the rooms to versions.
  - [ ] Per role: role cards in pairs; a room of three gives the third learner role A.
  - [ ] Learners choose: check the level picker, changing level after starting on and off.
- [ ] **While teaching:**
  - [ ] Use a group set and sync just one room; the other rooms stay where they are.
  - [ ] The live grid has a tab for each room and shows each learner's version, role or level.
  - [ ] Open each version to see its own answers.

## 2e Surveys, polls and team quiz
- [ ] **Survey:** / → Survey. Try each template and every question type (rating 1–5 and 1–10, faces, thumbs, one choice, several choices, ranking, open answer).
- [ ] **Anonymous survey:** a learner sends it. The teacher sees the results but no names; the CSV has no names.
- [ ] **Named survey:** the learner can change their answers; the teacher sees "From …" and names in the CSV.
- [ ] **Share results:** "Show results to the class". The learner sees the charts after answering and they update live.
- [ ] **Live poll:** Poll → quick types → Ask the class. The learner answers in the card. Stop answers, Open again, New poll.
- [ ] **Team quiz:** Team quiz → choose the task, the seconds and the teams (random, or the group set in use) → Start.
  - [ ] Learners see their team; after Lock in, the answer can't change.
  - [ ] The answer shows when everyone has answered or time runs out.
  - [ ] Points are higher for fast answers. The leaderboard follows each question and the podium comes at the end; End the quiz.

## 2f Question pack 1
- [ ] **Every new type:** add each one from / and answer it as a learner, then check:
  - [ ] Find and fix the mistake
  - [ ] Categorise
  - [ ] Key word transformation
  - [ ] Word formation (from the gap settings or / Word formation)
  - [ ] Highlight in text, with wrong taps costing a point on and off
  - [ ] Order sentences
  - [ ] Label the image (upload a picture, click to place points)
  - [ ] Odd one out, with a reason
  - [ ] Gapped text with an extra sentence
  - [ ] Multiple matching with names
- [ ] **Speaking prompt:** two photos, questions, the timer and "Your partner's turn".
- [ ] **Teaching screen:** Reveal and click-to-reveal write the answers in on your screen; the learner sees the answer under the question. The live grid shows a short answer for each new type.
- [ ] **Writing rubrics:**
  - [ ] Give a long answer the Cambridge-style scale and another one your own criteria, with a type of writing (essay, email…).
  - [ ] Mark each criterion in the learner's detail view.
  - [ ] The learner sees the breakdown with bars.
- [ ] **Exam mode on a task:**
  - [ ] Turn it on with 2 minutes. As a learner, Start, answer, and see the timer; there is no Check button.
  - [ ] Submit, and answers lock. Try another learner and let the time run out.
  - [ ] Release the results; learners see their scores. Take back hides them again.
- [ ] **Exam lesson:** change a lesson's type to Exam on the class page (the small label in front of its title). The learner home shows an Exams section; the whole lesson has one timer and one Submit.
- [ ] **Text format:** export a lesson that uses every new type, a survey, a rubric and `exam: 45min`, import it again, and compare.

## Mobile (phone or narrow window)
- [ ] The task list is a row of chips. Previous / Check / Next stay at the bottom; dialogs open from the bottom; typing in a gap doesn't zoom the page.
- [ ] Signals sit above the bottom bar; the poll card, team quiz and board fit the screen.

## Known limits (later phases)
- Rooms that share one answer, and reports in percentages, come with the reports phase (Phase 4).
- In an exam, a learner who is very determined could still change saved answers after submitting by changing the app's code; the security rules will check this when exams move to Cloud Functions (Phase 5).
- Board drawings stay in the Realtime Database; the full copy with drawings is Phase 4.
