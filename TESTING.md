# Phase 1 test checklist

Use two browsers (or one normal and one private window): one signed in as the teacher, one as a learner.
Fastest start: on the Classes page choose **Try a demo class** (or **Add a demo class**). It creates 6 learners and a sample lesson with every question type. The learner PINs are on the class's Learners tab.

## Sign-in and classes
- [ ] Teacher signs in with Google, with email and password, and with an email link.
- [ ] Learner joins at /join with the class code, chooses their name and types the PIN.
- [ ] Reset a learner's PIN; the old PIN stops working.
- [ ] Create, rename, archive and restore a class; change its theme colour and meeting link.
- [ ] Delete a class: it asks for the class name, then appears under Recently deleted. Restore it. Delete it again and choose Delete now.
- [ ] Topics: add, rename, move up and down, collapse, hide and lock. Learners don't see a hidden topic and can't open a locked one.
- [ ] Lessons: add, move up and down, move to another topic, hide, lock, duplicate, copy to another class.
- [ ] Profile pictures: choose one as the teacher and as a learner. A picture someone in the class has is shown as Taken.

## Building a task
- [ ] Type / and add every question type: gap, multiple choice in line and with radio buttons, true/false, matching, drag and drop with word bank, word order, long answer.
- [ ] Add hint and feedback to a question; add feedback for a wrong option; tick "Capital letters must match" on a gap.
- [ ] Drag a question by its dots to another place in the same line and to another line; click the dots and press Backspace.
- [ ] Copy and paste a question; the copy is a separate question.
- [ ] Right-click a word: definition, link, IPA, word stress, make it a gap / drag gap / multiple choice, highlight, colour, cut, copy, paste.
- [ ] Toolbar: bold, italic, underline, strikethrough, text colour, highlight, heading, lists, table, definition, link (task or web page), emoji, symbols.
- [ ] Table: add rows and columns from the + between cells, merge and split, cell colours, lines, striped rows.
- [ ] Text boxes and blocks: information box, page, web page, email, speech bubbles (left and right), sticky note; each coursebook block under / Blocks; reveal box; link card (YouTube, audio, web page); paragraph letters and line numbers.
- [ ] Draw a card, spin the wheel and open a box: change the look and card back; each card once and cards can repeat; start again when all are drawn.
- [ ] Self-reflection and peer feedback with every rating type; peer feedback with "I pair them" and "Send the feedback to the classmate".
- [ ] Message board and post-it wall: replies, reactions, anonymous, tagging on and off.
- [ ] IPA with the chart (British and American), computer voice and your own recording.
- [ ] Columns: equal, wide left, media + questions; scroll separately or together. On a phone the columns become tabs.
- [ ] Task settings: hidden, locked, after checking (show answers / try again), show score, teacher notes, version history (restore an earlier version).
- [ ] Preview as learner, check answers, try again.
- [ ] Export the lesson as text, change something in the file, import it from the class page. Break a line on purpose and see the problem with its line number.

## Teaching live
- [ ] Start teaching. The learner sees the teacher's marker and the Live now card. Turn "Show learners where I am" off and on.
- [ ] Learners type: answers appear in the live grid within about a second, with % correct and common wrong answers.
- [ ] Click a learner's name: their answers, and marking a long answer with a comment. The learner sees the mark.
- [ ] Sync class to me: the learner's screen follows the teacher; learners can't move away. Stop sync.
- [ ] Reveal next, reveal all, hide. Click a question to show only that answer. Show a single answer from the grid.
- [ ] Draw a card played "Together": every screen shows the same card. With "Any learner can draw", a learner draws for the class.
- [ ] Tag a learner on the message board: they get a notification with Go there.
- [ ] Shortcuts: ← → S R Shift+R H L C N P Esc ?; in the editor ⌘K, Alt+↑/↓, ⌘+Shift+P.
- [ ] Present mode hides the side panels; Live answers opens on top. Collapse the left and right panels.
- [ ] Stop teaching and start again.
- [ ] Text size (Aa) for the teacher and for a learner.

## Saving and connection
- [ ] Refresh in the middle of a task: answers are still there.
- [ ] Turn the Wi-Fi off, keep answering, see "Reconnecting…", turn it on again: the answers arrive.
- [ ] After a new version is published, open tabs show "A new version of Lesson Lit is ready".

## Account
- [ ] Privacy and Terms pages open from the sign-in page and the account menu.
- [ ] Delete my account (test with a spare teacher account only).
