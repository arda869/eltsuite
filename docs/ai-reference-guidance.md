# Reference-informed content guidance

## Scope of analysis
Representative sections were inspected, not every page of every supplied book. The sample included:
- New English File Elementary student material and workbook opening units.
- New English File Pre-Intermediate teacher overview and student reading sequence.
- English File fourth edition Beginner, Elementary, Intermediate and Upper-intermediate: course overviews and selected early lesson procedures.
- English File fourth edition Advanced Plus: overview and selected listening/pronunciation procedures.
- American English File third edition Level 2: skills sequence.
- The CELTA Course Trainer's Manual: introductory approach and teaching-practice feedback (printed page 174). The two supplied CELTA PDFs appear to be scans of the same manual.

Other supplied editions remain available for later targeted comparison; they have not all been reviewed.

## Original editorial decisions
The application receives abstract, original guidance only. No book pages, extracted passages, exercises, characters, scripts, scenarios or answer sets are included in prompts or deployed files. Do not use these books as a retrieval corpus. Do not paraphrase or closely adapt their materials. Renaming characters is not an acceptable originality strategy.

Language generation and advisory review share these expectations:
1. Give learners a reason to engage with input; successive encounters have distinct purposes.
2. Adjust input, support and response demands to the level, age and literacy context.
3. Integrate useful pronunciation work with perception, production and communication.
4. Keep spoken comparison as brief numbered prompts; use native reading blocks and related subtasks.
5. Differentiate access and challenge within an aim, with a teacher decision about when to use support.
6. Make homework workable independently and use fresh retrieval practice.
7. Keep keys, monitoring guidance and feedback procedures private and concrete.
8. Never claim unavailable media exists.

Teacher-training generation uses its own practical, experiential standard: experience/observe, analyse decisions, create or rehearse, evaluate evidence and plan a next attempt. Feedback focuses on learner response and a small number of actionable priorities. Historical manuals do not establish current examination requirements.

## Classroom recollections
This is separate from the reference books. The planning switch defaults off. When on, teachers load recent submitted writing from the current class and select up to five responses. Only server-reloaded selections and display names enter generation. Messages, portfolio narratives, files, unsubmitted drafts and other classes are excluded. Teachers should choose suitable low-stakes details and review outputs before sharing. The model is instructed to omit sensitive details and never treat an answer as verified biography. This instruction is not an infallible content filter.

Turning the switch off stops new retrieval; it does not redact previously generated or approved material. No option is persisted as an account-wide default.

## Validation and limits
Request-level tests verify that originality and the appropriate language/trainer guidance reach outline, plan, activity and review calls. Memory tests cover default-off no-read behaviour, bounded rich-text extraction, submitted-writing selection and server-side ID filtering. These are prompt and integration checks, not evidence that every generated lesson meets the standard. Teacher review remains necessary; no fine-tuning or guaranteed plagiarism detection is claimed.
