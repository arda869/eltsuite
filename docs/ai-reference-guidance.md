# Reference-informed content guidance

## Scope of analysis
Representative sections were inspected, not every page of every supplied book. The sample included:
- New English File Elementary student material and workbook opening units.
- New English File Pre-Intermediate teacher overview and student reading sequence.
- English File fourth edition Beginner, Elementary, Intermediate and Upper-intermediate: course overviews and selected early lesson procedures.
- English File fourth edition Advanced Plus: overview and selected listening/pronunciation procedures.
- American English File third edition Level 2: skills sequence.
- The CELTA Course Trainer's Manual: introductory approach and teaching-practice feedback (printed page 174). The two supplied CELTA PDFs appear to be scans of the same manual.

Other supplied editions remain available for later targeted comparison; they have not all been reviewed.

## Original editorial decisions
The application receives abstract, original guidance only. No book pages, extracted passages, exercises, characters, scripts, scenarios or answer sets are included in prompts or deployed files. Do not use these books as a retrieval corpus. Do not paraphrase or closely adapt their materials. Renaming characters is not an acceptable originality strategy.

Language generation and advisory review share these expectations:
1. Give learners a reason to engage with input; successive encounters have distinct purposes.
2. Adjust input, support and response demands to the level, age and literacy context.
3. Integrate useful pronunciation work with perception, production and communication.
4. Keep spoken comparison as brief numbered prompts; use native reading blocks and related subtasks.
5. Differentiate access and challenge within an aim, with a teacher decision about when to use support.
6. Make homework workable independently and use fresh retrieval practice.
7. Keep keys, monitoring guidance and feedback procedures private and concrete.
8. Never claim unavailable media exists.

Teacher-training generation uses its own practical, experiential standard: experience/observe, analyse decisions, create or rehearse, evaluate evidence and plan a next attempt. Feedback focuses on learner response and a small number of actionable priorities. Historical manuals do not establish current examination requirements.

## Classroom recollections
This is separate from the reference books. The planning switch defaults off. When on, teachers load recent submitted writing from the current class and select up to five responses. Only server-reloaded selections and display names enter generation. Messages, portfolio narratives, files, unsubmitted drafts and other classes are excluded. Teachers should choose suitable low-stakes details and review outputs before sharing. The model is instructed to omit sensitive details and never treat an answer as verified biography. This instruction is not an infallible content filter.

Turning the switch off stops new retrieval; it does not redact previously generated or approved material. No option is persisted as an account-wide default.

## Validation and limits
Request-level tests verify that originality and the appropriate language/trainer guidance reach outline, plan, activity and review calls. Memory tests cover default-off no-read behaviour, bounded rich-text extraction, submitted-writing selection and server-side ID filtering. These are prompt and integration checks, not evidence that every generated lesson meets the standard. Teacher review remains necessary; no fine-tuning or guaranteed plagiarism detection is claimed.

## Additional age and receptive-input analysis (1 November 2026)
Representative analysis added:
- Teen2Teen One teacher book: overview and methodology, PDF pages 4–7; grammar banks 1, 6 and 12; Unit 1 Test A/B and the corresponding answer-key section. These are teen references, not evidence that the same tasks suit pre-readers. The remaining supplied unit tests were not exhaustively reviewed.
- Navigate A1 teacher guide: reading and listening methodology, pages 20–23; coursebook contents and selected opening audioscripts. No recordings were supplied or listened to.
- Headway Elementary Culture and Literature companion teacher guide: opening procedure; Intermediate CLIL worksheets: selected explanatory reading and diagram sequence. Historical factual or safety advice is not adopted as current authority.

The resulting original guidance strengthens genre/purpose, textual coherence, adult relevance at beginner level, natural spoken exchanges, processing load, transferable receptive micro-skills and evidence-supported questions. It distinguishes exposure from a model for production. CLIL and cultural tasks must supply essential background, avoid stereotypes and identify facts needing verification. No source passage, scenario or exercise is included in deployed prompts.

Teen guidance adds age-respectful contexts, meaning and sound before recall, manageable rehearsal and optional personalisation. School-age assessment guidance checks taught constructs, unscored examples, marks, keys and genuinely comparable parallel forms. Existing pre-reader oral/pointing routes remain separate.

These standards apply to language outline, plan, activities and advisory review. They do not enter teacher-training or Teaching Coach prompts. The outline-only instruction still takes precedence: full texts and scripts belong in later material stages. Request-level tests exercise each age group and scope; they verify delivery of instructions, not the pedagogical quality of model output. No model fine-tuning is performed.

## Teacher feedback incorporated into generation
Learner instructions must name a concrete action and the information to find; methodological rationale stays private. Writing needs a recognisable genre, audience and purpose. Note-taking cannot be specified only as abstract grammatical categories. Separate changes of action into subtasks and independent messages into their own input boxes.

Native conversion now supports interactive definitions, compact short answers, categorisation, inline short choices, image groups and two-column tasks. Long writing fields remain for extended production. This does not yet constitute support for every editor tool; the broader tool catalogue requires additional contracts and validation.

The brief starts with a learning objective and context, with add/remove controls for further objectives. Legacy topics remain readable but are optional. Material references display titles. Activity review shows one selected activity at a time.

Media assets are generated in background jobs and saved before creation in Classes is permitted. Images use original prompts; audio uses explicit speaker turns and rejects a detected transcript mismatch. Completed takes are checkpointed for retries. Audio is labelled AI-generated. Teacher review of images and recordings remains necessary. Reservations share the existing monthly budget and conservatively retain reserved spend even when a provider failure leaves usage uncertain. No automatic paid retry occurs.

Current limits: four images/eight assets per lesson, two assets per task, twelve turns/4,000 characters per recording. Existing saved activities without media remain usable. These are bounded implementation limits, not teaching standards.
