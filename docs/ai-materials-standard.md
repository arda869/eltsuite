# AI materials editorial standard

The generator uses original pedagogical guidance in functions/ai/pedagogy.js at planning, review and activity-writing stages. No coursebook passages, images, worksheets or audio are embedded in prompts.

## Reference review (31 October 2026)

- [Oxford English File fifth edition teacher sample](https://www.oup.es/wp-content/uploads/2025/01/EF5e-Spain-A1-A2-TG-TR-SampleUnit-u7-1.pdf): learner and teacher text have different jobs; media tasks need usable input and a teaching sequence.
- [Pearson Speakout sample](https://www.pearsonelt.es/content/dam/professional/english/pearsonelt-es/materials/speakout/Speakout-Students-PreIntermediate.pdf): short action-led instructions, visual prompts with a purpose, preparation and subsequent interaction. These are general design observations, not templates to reproduce.
- [British Council guided discovery](https://www.teachingenglish.org.uk/professional-development/teachers/teaching-knowledge-database/d-h/guided-discovery): learners examine examples and infer patterns with guidance. It is an approach to choose deliberately, not an obligatory recipe for every lesson.

## Release acceptance

1. Learner wording is concise, level-appropriate and actionable. Aims and terminology remain in teacher notes.
2. Spoken dialogues have a listening purpose before transcript analysis; private teacher-read scripts are explicitly identified when no recording exists. Independent tasks never depend on a nonexistent recording.
3. Discovery examples do not reveal categories or rules before the learner's decision.
4. A useful visual has complete data, a learner action and text access. Native tables are rendered, not placeholder requests for images. This release does not automatically generate photographs or audio.
5. Alternative versions replace instructions, input and questions, with independent private keys. They retain the core objective. Legacy support paragraphs are not automatically converted into versions. Role cards retain separate private bodies.
6. No automatic learner grouping, fixed ability labels or invented evidence. Exams do not get adaptive versions that change the construct.
7. AI conversation inherits surrounding learner material on insertion and uses shared lesson focus when available. Starting a conversation does not override the server's role/scenario instructions.

Deterministic tests verify structure, keys, privacy, legacy jobs and conversion. They cannot certify pedagogical quality; review fresh model output before teaching.
